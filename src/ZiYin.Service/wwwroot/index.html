连接信息
更新会立即撤销旧密钥和所有 WebUI 会话。请保存新密钥。


后台命令
以服务账户 LocalSystem 执行 PowerShell。后台任务可以在锁屏时运行；命令具有高权限，请只交给可信的人。


文件
仅允许配置的文件根目录内操作，单文件最大 10 MiB。上传会覆盖同名文件。


普通桌面
须在本机托盘中手动开启。只支持活动控制台用户的普通桌面，不支持锁屏、登录界面、UAC 安全桌面或远程 RDP 会话。不能操作权限更高的窗口。


审计日志
记录任务状态和操作类型，不记录密钥、命令、文件内容或输入文字。






接入方式

Skill 调用

请为紫音 Windows 客户端创建并安装一个可真实调用的 Agent Skill。

需要创建：
- skills/ziyin-windows-client/SKILL.md
- skills/ziyin-windows-client/scripts/ziyin_client.py

参考模板：https://github.com/EisonMe/astrbot_plugin_ziyin_client/tree/main/skills/ziyin-windows-client
API 文档：https://github.com/EisonMe/ziyin-windows-client/blob/main/docs/API.zh-CN.md

Windows 客户端地址：<Agent 主机可访问的 Windows 客户端地址，例如 https://192.168.1.20:17643>
API Key：<从 Agent 的安全环境变量或凭证管理器读取，不要将真实密钥写进 Skill、日志或仓库>

连接和安全要求：
- 使用 Agent 主机实际可达的地址；不要把远程 Windows 主机误写成 localhost。
- 默认使用 HTTPS，并验证证书与主机名。自签名证书应配置受信任 CA，不要关闭验证。
- 仅在用户明确选择的可信隔离局域网中使用 HTTP。
- 先只读调用 GET /api/health。缺少真实地址或密钥时，报告尚未联通。
- 不要在 Skill、日志、命令行参数或仓库中保存真实 API Key。
- 执行命令、写文件、删除文件或控制桌面前，必须取得用户对该操作的明确授权。





AstrBot 插件调用

请通过 AstrBot 官方插件管理器的 GitHub 安装入口安装公开仓库：
https://github.com/EisonMe/astrbot_plugin_ziyin_client

安装后核对 metadata.yaml，并确认插件来自该仓库。安装和配置需要当前 AstrBot 实例管理员权限；如果没有权限，请报告未安装，不要声称已完成。

插件配置：
base_url = <AstrBot 主机可访问的 Windows 客户端地址，例如 https://192.168.1.20:17643>
api_key = <从 AstrBot 的安全配置或凭证管理器读取，不要写入仓库或日志>

这是 AstrBot 主机可达的 Windows 客户端地址，不要替换成 localhost。端口使用 Windows 客户端实际配置的端口，默认 17643。

安全要求：
- 默认验证 TLS 证书和主机名；自签名证书通过 ca_file 配置信任证书，不要关闭验证。
- 仅在用户明确选择的可信隔离局域网中使用 HTTP，并显式启用 allow_insecure_http。
- allow_group、allow_file_write、allow_desktop_control 保持关闭。
- 配置后只调用 ziyin_client_health 做只读连通测试。缺少真实地址或密钥时，报告尚未联通。
- 不执行命令或其他有副作用的操作，除非用户明确授权。






API 参考
敏感接口均需认证。不要把密钥放进 URL。HTTP 仅供明确可信的隔离局域网使用；公共网络请使用 TLS，且不要转发公网端口。
完整中文 API 参考 · curl / PowerShell
快速示例（使用环境变量存放密钥）
curl -H "Authorization: Bearer $ZIYIN_API_KEY" "$ZIYIN_BASE/api/health"

$headers = @{Authorization="Bearer $env:ZIYIN_API_KEY"; 'X-ZiYin-Request'='1'}
Invoke-RestMethod "$env:ZIYIN_BASE/api/tasks" -Method Post -Headers $headers `
  -ContentType 'application/json' -Body '{"command":"Get-Date","timeoutSeconds":30}'


退出托盘不会停止服务。关机、休眠或网络中断期间，远程 API 不可达。
